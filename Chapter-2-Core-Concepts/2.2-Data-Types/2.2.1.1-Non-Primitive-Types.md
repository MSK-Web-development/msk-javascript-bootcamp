# **Non-Primitive Data Types in JavaScript** (a.k.a. Reference Types)

These are **not stored directly by value**, but **by reference**. That means variables store a **reference (or address)** to the object in memory, not the object itself.

### 🌐 List of Non-Primitive (Reference) Types:

| Type                           | Example                         |
| ------------------------------ | ------------------------------- |
| **Object**                     | `{ name: "Manoj" }`             |
| **Array**                      | `[1, 2, 3]`                     |
| **Function**                   | `function() {}` or `() => {}`   |
| **Date**                       | `new Date()`                    |
| **RegExp**                     | `/abc/`                         |
| **Map**                        | `new Map()`                     |
| **Set**                        | `new Set()`                     |
| **WeakMap**                    | `new WeakMap()`                 |
| **WeakSet**                    | `new WeakSet()`                 |
| **Custom Classes / Instances** | `class User {}` or `new User()` |

---

## 🧠 Key Differences (vs Primitive Types)

| Feature        | Primitive                                                              | Non-Primitive                               |
| -------------- | ---------------------------------------------------------------------- | ------------------------------------------- |
| **Stored as**  | Value                                                                  | Reference (pointer)                         |
| **Mutable?**   | No                                                                     | Yes                                         |
| **Type check** | `typeof` returns type (e.g. `"string"`)                                | `typeof` returns `"object"` or `"function"` |
| **Copying**    | Copies value                                                           | Copies reference (shared memory)            |
| **Examples**   | `string`, `number`, `null`, `boolean`, `undefined`, `symbol`, `bigint` | `object`, `array`, `function`, etc.         |

---

### 🧪 Example:

```js
let obj = { name: "Manoj", role: "Engineer" }; // [Object] "Key-value pairs"

let arr = [1, 2, 3, 4]; // [Array] "Indexed collection, subtype of Object"
let arr2 = new Array(5); // [Array] "Array with 5 empty slots"

let func = function greet(name) {
  return `Hello, ${name}`;
}; // [Function] "Callable object"
let arrowFunc = (x) => x * 2; // [Function] "Arrow function expression"

let date = new Date(); // [Date] "Represents date and time"

let regex = /hello/i; // [RegExp] "Pattern matcher, case-insensitive"
let regex2 = new RegExp("world", "g"); // [RegExp] "Using RegExp constructor"

let map = new Map(); // [Map] "Key-value pairs with any data type as key"
map.set("id", 101);

let set = new Set([1, 2, 2, 3]); // [Set] "Unique values only"

let weakMap = new WeakMap(); // [WeakMap] "Holds weak object keys"
let objKey = {};
weakMap.set(objKey, "secret");

let weakSet = new WeakSet(); // [WeakSet] "Holds weak object references"
let anotherObj = {};
weakSet.add(anotherObj);
```

---

## 🎯 Summary

### 🧩 Non-Primitive Types:

- **Objects**
- **Arrays**
- **Functions**
- **Built-in classes like Map, Set, Date, RegExp**
- **Custom class instances**

They are all mutable, reference-based, and powerful — but require careful handling due to shared memory behavior.
